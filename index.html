    Privacy guarantee

    We never upload PDFs to a server. Files are read in the browser, processed locally, and kept in memory only until download.

    How it works

    • PDF files are loaded in the browser.

    Built for real life

    Questions

    Common topics

    Does it upload my files?

    No. All PDF processing happens on your device. The browser reads files locally and merges them in place.

    Can I reorder the final file order?

    Yes. Use drag-and-drop, the move buttons, or sorted order controls before merging.

    What happens if the worker fails?

    The app automatically falls back to a main-thread merge after a watchdog timeout so the process keeps working.
